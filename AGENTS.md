# JXHQ repository instructions

## Lab publishing contract

Whenever a public repository is created, renamed, published, or substantially updated, verify its JXHQ Lab presentation before considering the work complete.

- Public repositories are included in `https://jxhq.net/lab/` automatically unless they use the `hide-from-lab` topic.
- Give every included repository a concise public description.
- Set the repository homepage when a live demo, documentation site, or deployed application exists.
- Keep repository topics accurate. Optional presentation topics are `featured`, `prototype`, and `probably-broken`.
- Archived repositories may remain visible but must be presented as archived.
- Never expose private repositories, secrets, internal hostnames, credentials, or deployment tokens through Lab.
- When a repository becomes public, check that its README, license, description, homepage, and Lab card tell a consistent story.

This checklist applies even when a user does not explicitly mention Lab during repository work.
